# YapDol - One Pager Pitch

---

## The Problem

### K-Pop Fan Economy is Broken

**$5.9B** - Global K-Pop market size (2024)
**300M+** - Active K-Pop fans worldwide

Despite this massive scale, fans face critical issues:

| Problem | Impact |
|---------|--------|
| **Uncompensated Labor** | Fans spend hours streaming, voting, and promoting - receiving nothing in return |
| **No Ownership** | Fan contributions build artist value, but fans have no stake in that success |
| **Opaque Systems** | Traditional voting and fan activities lack transparency and verifiability |
| **Wasted Engagement** | Millions of social media posts promoting artists create no lasting value for creators |

---

## The Solution

### YapDol: Social Mining Protocol for Fandoms

**"Turn Every Tweet Into Tokens"**

YapDol transforms fan promotion activities ("Yapping") into measurable, rewarded contributions on the blockchain.

```
[Fan Posts on Social Media] --> [Submit URL to YapDol] --> [Earn Hype Points] --> [Swap for Artist Tokens]
```

### Core Features

| Feature | Description |
|---------|-------------|
| **Social Mining** | Fans earn Hype Points by submitting proof of social media promotion |
| **Token Economy** | Points convert to Artist Tokens with real utility and governance rights |
| **Transparent Tracking** | All activities recorded on-chain via Mantle L2 |
| **Dual System** | Support trainees (pre-debut) OR invest in debuted icons |

## Business Model

### Revenue Streams

```
                    YapDol Platform
                          |
    +---------+-----------+-----------+---------+
    |         |           |           |         |
 Listing   Campaign    Premium    Token Swap  NFT
   Fee      Fees       Features     Fees     Marketplace
    |         |           |           |         |
   1-3%     10-15%      $9.99/mo     0.5%     2.5%
```

| Stream | Model | Target |
|--------|-------|--------|
| **Agency Listing Fee** | Per-artist onboarding fee | Entertainment companies |
| **Campaign Fees** | % of promotional campaign budgets | Agencies running campaigns |
| **Premium Membership** | Monthly subscription for advanced features | Power fans |
| **Swap Transaction Fee** | Small % on Hype Points to Token swaps | All users |
| **Future: NFT Marketplace** | Trading fees on fan-created content | Fan creators |
